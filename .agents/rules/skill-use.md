# Skill Use

Use only when specialized knowledge is needed.

- Load skills on demand based on the current task; do not preload unrelated skills.
- Prefer one or a small set of directly relevant skills.
- Do not duplicate skill content in `AGENTS.md` or `GEMINI.md`.
- When an installed library/framework API is imported, configured, or validated, use the project's approved documentation/reference skill or source-of-truth documentation.
