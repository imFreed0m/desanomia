# Hardware Documentation

Applies only to `hardware/**`.

## Rules

- Treat `docs/CONSTITUTION.md` and `docs/SPEC.md` as authoritative for safety and frozen field constraints.
- Document hardware/BOM changes without modifying application code unless the task explicitly requests integration.
- Do not reintroduce rejected components or architectures.
- Keep pinout, wiring, BOM, electrical constraints, and physical assumptions explicit and traceable.
- Verify proposed changes against existing system architecture before recording them.
